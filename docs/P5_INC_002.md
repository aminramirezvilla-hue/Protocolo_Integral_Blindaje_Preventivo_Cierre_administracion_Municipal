# P5-INC-002 — Inconsistencia de estados permitida

**Fecha de detección:** 2026-09-13  
**Rama:** `dev/v0.1.4`  
**Runtime afectado:** `0.1.4-dev.2`  
**Caso asociado:** `P5-0301`  
**Severidad:** B1 — Crítica / bloqueante para promoción  
**Estado:** Abierta; pendiente de corrección y re-prueba

## Evidencia de reproducción

Con el perfil **Administrador municipal**, el control **R074 — Obligaciones de transparencia, datos personales y archivos** permitió guardar y persistir la combinación:

- `Estatus diagnóstico = Conforme`
- `Estatus evidencia = Insuficiente`
- `Validación OIC = Pendiente`

La combinación persiste al cerrar y volver a abrir el modal.

## Riesgo funcional

El sistema permite declarar un control como `Conforme` aun cuando la evidencia mínima sea insuficiente. Esto produce una contradicción semántica entre diagnóstico y soporte documental, afecta la confiabilidad del IPER-CATU y puede inducir reportes ejecutivos inconsistentes.

## Criterio de corrección

Debe incorporarse una validación central previa a persistir cambios. Como mínimo:

1. `Conforme` no puede coexistir con evidencia `Insuficiente`, `Parcial` o `No evaluada`.
2. La aplicación debe bloquear el guardado y explicar la incompatibilidad, sin normalizar silenciosamente los datos.
3. `Validación OIC = Pendiente` puede coexistir con `Conforme`; el cierre definitivo sólo procede con `Conforme + Completa verificada + Validado`.
4. La validación debe aplicarse antes de persistir para impedir combinaciones inválidas.

## Re-prueba obligatoria

- P5-0301-A: `Conforme + Insuficiente + Pendiente` → bloqueo, sin persistencia.
- P5-0301-B: `Conforme + Parcial + Pendiente` → bloqueo, sin persistencia.
- P5-0301-C: `Conforme + No evaluada + Pendiente` → bloqueo, sin persistencia.
- P5-0301-D: `Conforme + Completa verificada + Pendiente` → permitido, pero no cerrado.
- P5-0301-E: `Conforme + Completa verificada + Validado` → permitido y cerrado.
- P5-0301-F: cerrar/reabrir modal y recargar Safari → sólo persiste el último estado válido.

La incidencia podrá cerrarse únicamente cuando todos los casos anteriores resulten `PASS` y no se detecten regresiones en permisos de P5-0203.
