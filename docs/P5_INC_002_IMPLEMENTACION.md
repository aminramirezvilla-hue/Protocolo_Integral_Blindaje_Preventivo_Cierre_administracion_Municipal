# Implementación P5-INC-002

Parche propuesto: `js/patch-p5-dev3.js`.

Objetivo: impedir la persistencia de `Conforme` cuando el estado de evidencia sea `Insuficiente`, `Parcial` o `No evaluada`, sin exigir todavía `Validación OIC = Validado` para guardar el diagnóstico.

La incidencia permanece abierta hasta completar la re-prueba P5-0301-A a P5-0301-F.
